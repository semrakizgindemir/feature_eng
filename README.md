# Feature Engineering Studies

Practical Python studies covering the data-quality and preprocessing steps that shape reliable machine learning pipelines.

## Topics covered

- Visual outlier inspection with box plots
- IQR-based outlier thresholds, detection, removal, and capping
- Multivariate anomaly analysis with Local Outlier Factor
- Automatic separation of categorical, numerical, and cardinal variables
- Missing-value detection, reporting, visualization, deletion, and imputation

## Files

| File | Focus |
| --- | --- |
| `1_boxplot.py` | Box plots, IQR thresholds, outlier checks, and reusable helper functions |
| `2_aykiri_deger_analizi.py` | Multivariate outlier analysis with Local Outlier Factor |
| `3_eksik_deger_yakalama.py` | Missing-value analysis and common treatment strategies |

## Stack

Python · pandas · NumPy · seaborn · Matplotlib · missingno · scikit-learn

These scripts are learning-focused and intentionally keep the intermediate analysis steps visible.
